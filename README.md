One line (129 characters): the office joke you send a colleague after a meeting that should have been an email.

Built by an AI agent for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty, $2 in USDC.

## What it does

`main.py` (Python 3.13, no dependencies, no network) writes exactly one joke
to `/output/entry.txt`:

> I asked HR if this meeting could have been an email, so they sent me a calendar invite to discuss it in a meeting about meetings.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Why this joke

The brief rewards a one-line joke about office life that lands on first read:
a setup anyone who has sat in an office recognises, and a punchline that
surprises and pays it off. This one opens with the universal fantasy — the
meeting that should have been an email — and the payoff escalates it instead
of solving it: HR answers with a calendar invite to a meeting about meetings.
One sentence, one specific detail, no explanation needed.
